# 🧠 **Moving Robot — Graphical Edition**

**Moving Robot — Graphical Edition** is an enhanced version of the original robot movement simulation, developed in **Python** using **Tkinter** to provide a more interactive and visually engaging experience.  
While maintaining the original simulation logic, this upgraded edition introduces a graphical map, live interaction tools, and extended customization options to improve usability and immersion.

---

## 🎮 **How to Use**

- Load or create a new map within the graphical interface.  
- Use the on-screen buttons to **start**, **pause**, **restart**, or **clear** the simulation.  
- Interactively **edit the map** by placing or removing obstacles.  
- Press the **“Change Background”** button to instantly switch the background color.  
- Observe the robot’s movement in real-time with color-coded visualization.  
- Track simulation progress using the built-in real-time timer.  

---

## ✨ **Features**

- 🗺️ **Graphical Map Visualization:** Displays a color-coded grid with obstacles highlighted in red.  
- 🎨 **Interactive Map Editor:** Allows users to design and customize the map layout directly.  
- ⏱️ **Real-Time Timer:** Tracks the duration of each simulation.  
- 🎛️ **Change Background Button:** Instantly changes the background color when pressed.  
- 🧩 **Control Buttons:** Start, pause, restart, set starting point, or clear the map.  
- ⚡ **Interactive Simulation:** Provides instant visual feedback for every user action.  

---

## ⚙️ **Technologies Used**

- 🐍 **Python 3**  
- 🪟 **Tkinter** – graphical interface and event handling  
- 🧠 **Algorithmic Logic** – map validation, robot movement, and interaction control  
- ⏰ **Real-Time Updating** – continuous refresh and simulation timing management
